# Elvento Labs

[Elvento Labs Private Limited](https://elvento.com/) is an independent mobile game studio based in Indirapuram, Ghaziabad (Delhi NCR), Uttar Pradesh, India. We have been building software since 2016 and today focus on free-to-play Android games and mobile game development services.

## Our games on Google Play

- **Vendatta: Stealth Shooter** - a stealth action shooter.
- **Color King: Rangoli Puzzle** - a relaxing colour puzzle inspired by Indian rangoli art.
- **Last Attendance: Hostel 13** - a story-driven horror adventure set in a college hostel.
- **Gully Ka King: Street Cricket** - fast street cricket, Indian gully style.
- **Motion Archery** - a physics-based archery game.

See all games at [elvento.com](https://elvento.com/).

## Services

We help studios and brands ship mobile games:
